#### This repo: my portfolio site

An engineering-blueprint × comic portfolio, illustrated with my own character drawings:

- **Four case studies** told as drawing sheets: Traxen AI, BuyMySpot, GuardianCare and a luxury vehicle × GM cabin you can try.
- **The Lab:** things I built with AI, like ASCII Hands (steer a globe with your hands, through your webcam).
- **The Garage:** branding, posters, merch, VR and research side projects.

Built with Vite + React + TypeScript, published to GitHub Pages on every push to `main`.

```bash
npm install
npm run dev
```

`npm run build` writes the static site to `dist/`.
